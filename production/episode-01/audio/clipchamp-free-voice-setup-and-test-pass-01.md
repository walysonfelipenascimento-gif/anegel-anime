# ANGEL — configuração de teste de vozes no Microsoft Clipchamp

**Data:** 13/11/2026  
**Ferramenta de teste escolhida:** Microsoft Clipchamp — conversão de texto em fala.  
**Motivo:** alternativa para começar sem comprar créditos.  
**Estado:** plano preparado; ainda não foram gerados ou aprovados áudios.

## Regra de custo

Usar somente os recursos que a interface disponibilizar gratuitamente. Não ativar plano pago, assinatura, teste com cobrança futura, compra de créditos ou recurso premium. Se a interface pedir pagamento para qualquer etapa, parar e não confirmar.

A disponibilidade de vozes, limites, exportação e condições pode mudar por região, conta e atualização do produto. Conferir a indicação de preço na interface antes de usar. Não prometer gratuidade ilimitada.

## Acesso

- Site: https://clipchamp.com/
- Entrar pelo site oficial e abrir a ferramenta de texto para fala.
- Escolher idioma/variante Português (Brasil), quando disponível.
- Não compartilhar senha, código de acesso ou dados pessoais nesta conversa.
- Não usar clonagem de voz de pessoa real nem imitar ator, dublador ou celebridade.

## Fluxo de teste

1. Criar um projeto de teste separado, sem montar ainda o episódio.
2. Abrir texto para fala e escolher Português (Brasil).
3. Ouvir as prévias das vozes disponíveis e selecionar candidatas com timbres distintos.
4. Gerar cada frase isoladamente, uma por personagem, para comparar a mesma interpretação.
5. Salvar/exportar somente se a opção estiver disponível gratuitamente; se não, ouvir a prévia e registrar as limitações.
6. Não misturar, publicar ou tratar as amostras como dublagem final.

## Comparação e aprovação

Para cada personagem, comparar até três vozes que estejam disponíveis sem pagamento. Manter as mesmas frases para todas as candidatas. Avaliar:

- Naturalidade e pronúncia pt-BR.
- Clareza e inteligibilidade.
- Emoção compatível com a cena.
- Ritmo, pausas e entonação.
- Consistência entre frases curtas e longas.
- Distinção entre personagens.

Não escolher voz definitiva com base numa única frase. Se a ferramenta não oferecer variedade ou interpretação suficiente, registrar a limitação e procurar outra opção gratuita antes de aprovar.
